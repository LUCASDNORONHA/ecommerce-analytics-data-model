# Sistema de Gestão Logística Integrada (SGLI)

## Descrição
Este projeto tem como objetivo a análise de requisitos e a modelagem de dados de um sistema de gestão logística, voltado ao controle e rastreamento de operações de transporte, armazenamento e distribuição de mercadorias.

A proposta é estruturar uma base de dados consistente e aderente às regras de negócio do domínio logístico, simulando um ambiente profissional de engenharia de dados.

---

## Objetivos
- Levantar e documentar requisitos do sistema
- Modelar entidades e relacionamentos do domínio
- Garantir integridade e consistência dos dados
- Estruturar documentação técnica de forma profissional

---

## Escopo
O sistema contempla:

- Cadastro de clientes
- Registro de pedidos
- Controle de entregas
- Gerenciamento de veículos
- Rastreamento de operações logísticas

---

## Metodologia
O projeto segue uma abordagem incremental, com gestão ágil por meio de Kanban, permitindo refinamento contínuo dos requisitos e evolução progressiva da modelagem de dados.

---

## Estrutura do Projeto

📁 docs/ -> Documentação técnica (análise de requisitos)

📁 model/ -> Modelos conceitual e lógico

📁 data/ -> Bases de dados utilizadas

📁 scripts/ -> Scripts auxiliares (quando aplicável)
