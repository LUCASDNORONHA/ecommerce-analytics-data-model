# Modelo de Dados para Análise de Desempenho Logístico em E-commerce

## Descrição
Este projeto tem como objetivo a análise de requisitos e a modelagem de dados voltadas à avaliação do desempenho logístico em operações de comércio eletrônico.

A proposta consiste na estruturação de uma base de dados analítica, capaz de integrar informações de pedidos, pagamentos, entregas e avaliações, permitindo a extração de indicadores e suporte à tomada de decisão orientada a dados.

O projeto simula um ambiente profissional de engenharia de dados, com foco na organização, consistência e interpretabilidade das informações.

---

## Objetivos
- Levantar e documentar requisitos do sistema
- Modelar entidades e relacionamentos do domínio de e-commerce
- Garantir integridade, consistência e qualidade dos dados
- Estruturar uma base adequada para análise de desempenho logístico
- Produzir documentação técnica com rigor profissional

---

## Escopo
O sistema contempla a análise de dados relacionados a:

- Clientes (dados não sensíveis)
- Pedidos e seus status
- Itens de pedidos
- Produtos
- Vendedores
- Pagamentos
- Avaliações de clientes

Estão incluídas análises como:

- Tempo de entrega de pedidos
- Identificação de atrasos
- Desempenho de vendedores
- Relação entre prazo de entrega e satisfação do cliente

Não fazem parte do escopo:

- Controle operacional em tempo real
- Gestão de frota ou veículos
- Rastreamento logístico em tempo real
- Dados sensíveis ou pessoais identificáveis

---

## Metodologia
O projeto segue uma abordagem incremental, com organização das atividades por meio de Kanban, permitindo refinamento contínuo dos requisitos e evolução progressiva da modelagem de dados.

A condução é orientada por boas práticas de engenharia de requisitos e modelagem relacional, respeitando a separação entre análise conceitual, modelagem lógica e implementação.

---
