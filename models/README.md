# Modelos de dados

Este diretório reúne os artefatos de modelagem do projeto.

- `conceptual/`: entidades, relacionamentos, cardinalidades e diagramas MER;
- `logical/`: tabelas, atributos, chaves e restrições independentes de SGBD;
- `physical/`: implementação específica do banco de dados escolhido.

Os diretórios serão preenchidos progressivamente conforme o modelo relacional for desenvolvido e validado.
