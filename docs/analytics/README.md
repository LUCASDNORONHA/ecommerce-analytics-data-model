# Documentação analítica

Documentação consolidada da camada analítica, destinada à leitura humana e ao
consumo por SQL e ferramentas de Business Intelligence.

## Artefatos

- [`camada_analitica.pdf`](camada_analitica.pdf): versão final para leitura e
  distribuição e único artefato publicado da documentação consolidada.

O documento reúne contrato analítico, evidências das consultas, validação dos
requisitos funcionais, catálogo de métricas, estruturas do schema `analytics` e
contrato de consumo no Power BI e SQL.
