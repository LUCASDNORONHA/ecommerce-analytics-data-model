# Consultas analíticas

Este diretório contém consultas SQL versionadas direcionadas principalmente ao modelo `core`.

- `basic/`: exploração fundamental de tabelas, filtros, ordenações e agregações;
- `analysis/`: consultas que combinam entidades para responder a perguntas analíticas;
- `validation/`: consultas de controle e validação dos resultados.

Estruturas persistentes do schema `analytics`, como views e marts, pertencem a
`models/analytics/`.
